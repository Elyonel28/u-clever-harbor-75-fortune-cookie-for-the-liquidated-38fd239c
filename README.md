# Fortune Cookie for the Liquidated Trader

A single fortune cookie line for a crypto trader who has just been liquidated — oracular on the outside, a joke on the loss on the inside.

## The fortune

> You will meet a wealthy stranger soon: it is you, in five years, still laughing about this liquidation.

18 words, 103 characters, one line of plain text.

## Run

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable) and checks the bounty gate first: UTF-8 text, 1–160 characters, a single line, at most 20 words.
